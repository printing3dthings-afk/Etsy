Privacy Policy

Application: OnBrandCraftz Hub
Owner: OnBrandCraftz (etsy.com/shop/onbrandcraftz)
Last updated: July 18, 2026

Overview

OnBrandCraftz Hub is a private shop-management tool used solely by the owner of the OnBrandCraftz Etsy shop to run day-to-day shop operations, including an AI assistant that helps answer questions about orders, listings, and reviews. It is not a public application and is not available to third parties. This page covers data the Hub tool itself accesses and stores while doing that — including a limited amount of data about the shop's customers, described below. It does not cover Etsy's own handling of your data as the marketplace operator; see Etsy's Privacy Policy (linked below) for that.

Data We Access

This application connects to Pinterest and Etsy APIs exclusively on behalf of the shop owner. The following data may be accessed:

  • Pinterest boards and pins belonging to the authenticated account, and Pinterest account profile information
  • Etsy shop listings, sales/traffic metrics, and financial summaries belonging to the shop owner
  • Customer order data: order ID, buyer name, order total, item count, and order date, for the shop's own paid orders (via Etsy's Orders API)
  • Customer review data: star rating, review text, and which listing a review is for
  • Customer message/review text, when the shop owner asks the assistant to help draft a reply to a buyer message or review

Buyer email addresses and shipping addresses are never accessed by this application.

How Data Is Used

All accessed data is used solely to manage and operate the OnBrandCraftz Etsy shop. Specifically:

  • To create and schedule Pinterest pins promoting shop products
  • To answer the shop owner's questions about recent orders, sales trends, and reviews
  • To send the shop owner an email notification when a new order comes in (order ID, buyer name, item, total)
  • To draft suggested reply text to a buyer message or review — every draft is reviewed and sent by the shop owner personally; nothing is sent to a buyer automatically
  • No data is sold or shared with any third party for marketing or any purpose beyond operating this shop

Data Storage & Retention

API access tokens are stored, encrypted, on the shop owner's private server. Order-notification records and draft reply text are kept locally for up to 90 days and then automatically deleted — Etsy remains the authoritative record of all order and message history for longer than that. The AI assistant's own chat history deliberately does not save any conversation turn in which a buyer name was looked up, so buyer names are not retained in searchable chat logs. A buyer's name or review/message text may pass briefly through the third-party AI services listed below while a request is being answered or a reply is being drafted, under those providers' own data-handling terms.

Your Rights

If you are an Etsy customer of this shop and want to know what data we hold about you or want it deleted, contact the shop owner (below) and we will respond within 30 days. Because Etsy is the platform operating the underlying marketplace transaction, most account, payment, and order data is controlled by Etsy directly — see Etsy's Privacy Policy to manage that data or exercise rights (including GDPR rights, if applicable to you) with Etsy.

Third-Party Services

This application uses the following third-party APIs under their respective terms of service:

  • Pinterest API — pinterest.com
  • Etsy Open API — etsy.com
  • Anthropic Claude API — anthropic.com
  • OpenAI API — openai.com (used for image generation, not for order/message data)

Contact

This is a private shop-management tool, not a public application. For any question about this policy or your data, contact the shop owner via the Etsy shop: etsy.com/shop/onbrandcraftz
