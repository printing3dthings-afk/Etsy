# Privacy Policy — OnBrandCraftz

**Last updated: June 3, 2026**

## About This App

OnBrandCraftz Pin Scheduler is a private automation tool used exclusively by OnBrandCraftz to create and schedule Pinterest pins linking to product listings in the OnBrandCraftz Etsy shop. This is not a public-facing application.

*(This document covers the Pinterest pin-scheduling tool only, which never touches customer/order data. For the broader shop-management Hub tool — which does access limited customer order and review data — see [privacy.html](privacy.html)/`/static/privacy.html`.)*

## Data We Access

This app accesses the Pinterest API on behalf of the OnBrandCraftz business account only. It does not access, store, or process any data belonging to Pinterest users other than the account owner.

The app uses the following Pinterest API scopes:
- **pins:read** — to check existing pins
- **pins:write** — to create new pins
- **boards:read** — to read board information
- **boards:write** — to create and manage boards

## Data We Collect

This app does not collect personal information from any users. It only processes:
- Product listing data from the OnBrandCraftz Etsy shop (titles, descriptions, images, prices)
- Pinterest board and pin data for the OnBrandCraftz Pinterest account

All data is processed locally on the shop owner's private server and is not transmitted to any third party.

## Data Storage

OAuth tokens are stored locally in a private `.env` file on the shop owner's server. No data is stored in external databases or shared with third parties.

## Third-Party Services

This app integrates with:
- **Pinterest API v5** — for creating and scheduling pins
- **Etsy API v3** — for reading product listing data

Both integrations are subject to their respective terms of service and privacy policies.
