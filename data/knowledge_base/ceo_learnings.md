# CEO Agent Learnings — Frank's Compounding Knowledge

Append-only log. Frank (the CEO Agent) writes a short dated entry here via the
`log_learning` tool whenever a conversation surfaces a durable, non-obvious
insight about the business — a pattern in what converts, a recurring buyer
question, a preference Scott stated, a mistake worth not repeating. This file
is re-read fresh on every chat turn (see `_ceo_learnings_block()` in
`tools/api_server/main.py`), so insights compound across sessions instead of
evaporating when a chat ends — this is Frank's mechanism for getting smarter
about THIS business over time rather than starting cold every conversation.

Keep entries short — one or two lines. This is a memory log, not a report.
Scott can edit or delete any line directly; nothing here is authoritative
over CLAUDE.md or the live data tools — it's supplementary judgment, not a
source of truth for numbers (always pull live figures via get_metrics /
list_listings instead of trusting a remembered figure here).
