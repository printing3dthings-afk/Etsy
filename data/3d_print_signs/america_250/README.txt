OnBrandCraftz — America 250th Anniversary Sign SVG Pack
=======================================================
5 patriotic sign designs, each sized 235x235mm for direct import into Bambu Studio.
(235mm slices cleanly on a Bambu P1S/P2S/X1C 256mm plate WITH the AMS prime tower —
no "outside printable area" warnings. Scale up or down freely; SVG is vector.)

FILES INCLUDED:

  SS1001_america250_medallion.svg — Circular coin/seal design  (navy/gold/red/cream)

HOW TO PRINT (Bambu Studio):
  1. Drag & drop the SVG into Bambu Studio (or File > Import).
     Studio extrudes it into a 3D object automatically — set the height to 6mm.
  2. Add your filament colors: in the Filament list (left panel), click "+"
     and add all 4 colors for your chosen design.
  3. Open the Color Painting tool (press N, or the paint-roller icon in the
     top toolbar) and choose the FILL tool. Click each region of the design
     to assign its color. The regions are clean closed shapes, so painting
     a whole sign takes about 2 minutes.
  4. Slice. Bambu Studio automatically maps each painted color to the
     closest AMS slot — double-check the mapping in the print dialog.
  5. Print!

  NOTE: Bambu Studio imports a multi-color SVG as a single object — it cannot
  split it by color (that menu option does not exist). The Color Painting
  FILL tool is the correct, official way to color the design. Don't worry,
  it's fast and the results are identical.

PRO TIP — FLAT GLOSSY-SMOOTH FACE:
  Print the sign FACE-DOWN on a textured PEI plate. The design face comes out
  perfectly flat with a beautiful uniform matte grain — no layer lines visible.
  (Flip the model in Bambu Studio so the design face is on the build plate.)

RECOMMENDED SETTINGS:
  Layer height: 0.2mm | Outer wall speed: 50mm/s | Infill: 15% gyroid
  Total height: 6mm (set when importing the SVG)

FILAMENT SUGGESTIONS:
  Navy/Royal Blue PLA, Deep Red PLA, Gold Silk PLA, Cream/White PLA
  (Gold Silk PLA gives a premium metallic shimmer on the gold elements!)

SIZE & SCALING:
  Default: 235x235mm (~9.25x9.25 inches) — fits a Bambu 256mm plate with prime tower
  To resize: scale uniformly in Bambu Studio before slicing
  Going bigger? Up to ~250mm fits a P1S if you relocate/disable the prime tower.

NO AMS? You can still print these:
  - Single color: skip painting, print in one filament — still looks great.
  - Manual swaps: use "Change Filament" pauses at layer heights (works best
    for designs where colors stack by height rather than sit side-by-side;
    these signs are side-by-side, so AMS or painting + AMS is recommended).
