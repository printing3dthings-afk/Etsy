⚙️ Setup & Connections

🛒 Connect Your Etsy Shop

1. Open PowerShell in your Etsy folder
2. Run: python tools\etsy_oauth.py
3. A browser window opens — log in and click Allow
4. Tokens save to .env automatically
5. Restart Start Town.bat

Need an API key? Visit etsy.com/developers → create app → copy Keystring into .env as ETSY_API_KEY=
🎨 Enable AI Art Generation (DALL-E 3)

Without an OpenAI key, the Art Agent creates styled concept-card images.
For real AI art: platform.openai.com → API Keys → Create key
Add to .env: OPENAI_API_KEY=sk-... then restart.
