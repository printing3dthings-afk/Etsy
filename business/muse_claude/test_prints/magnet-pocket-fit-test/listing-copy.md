# TEST — Magnet Pocket Fit Test

Title: TEST — Magnet Pocket Fit Test

## Description

A magnet pocket that's 0.1 mm too small splits its wall; 0.1 mm too big
and the magnet rattles or falls out. This plate finds your printer's
number for the common sizes in one print.

The plate (110 x 108 x 5 mm) carries blind pockets for 6x2, 6x3, 8x2 and
10x2 mm round magnets plus a 10x5x2 mm bar. Every size is printed four
times, with the pocket opened up by +0.2, +0.3, +0.4 and +0.5 mm over the
magnet's nominal size (both dimensions for the bar). Pocket depth is the
magnet height + 0.2 mm. Sizes and clearances are engraved on the plate.

Magnets are NOT included — you supply your own. Measure your actual
magnets with calipers first if you can; magnet batches vary, and the
pocket that fits is the one matched to the magnet you measured.

### How to test

Drop the right magnet into each pocket in its row. The fit you want for a
press-fit is: goes in with firm thumb pressure and stays when the plate
is turned over and tapped. Record per size which clearance gives that —
looser columns are glue-in fits, tighter ones won't seat at all.

| Magnet | +0.2 | +0.3 | +0.4 | +0.5 | Best press-fit |
|---|---|---|---|---|---|
| 6x2 |  |  |  |  |  |
| 6x3 |  |  |  |  |  |
| 8x2 |  |  |  |  |  |
| 10x2 |  |  |  |  |  |
| 10x5x2 bar |  |  |  |  |  |

(Write P = press-fit by thumb, G = needs glue, F = falls out, X = won't seat.)

### Profiles and material

Both profiles are matte white PLA, 3 walls, supports off, no ironing (an
ironing pass can lip a pocket mouth, and the pocket mouths are the fit
surface being measured). Pocket sizes are identical in both — only the
layer height differs:

- Standard: 0.20 mm Standard - verified slice 54 min 08 sec - 39.60 g
- Optimized: 0.16 mm Optimal - verified slice 1 hr 12 min - 43.97 g (finer layers
  make rounder pocket walls — if your best-fit column moves, that's why)

MakerWorld may display its own re-sliced time and filament estimates.
