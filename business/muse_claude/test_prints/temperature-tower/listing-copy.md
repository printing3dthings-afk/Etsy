# TEST - Temperature Tower

**Title (MakerWorld, <= 50 chars):** TEST - Temperature Tower

**What it tests:** nozzle temperature, isolated. The same tower printed
at five temperatures - and because temperature cannot vary inside one
sliced file honestly, the five values are five PROFILES of one model:
identical geometry, identical everything, only the filament preset's
nozzle temperature differs (first layer and all layers, verified in
each file's config).

**The tower:** five steps (46 -> 30 mm footprints, 9 mm each, staircase
offset) on a 58 x 58 mm slab. Every step carries the same three
features: a through window (its roof is a bridge), a 45-degree notch in
the front face (its roof is an overhang underside), and the shared
central 6 mm hole. Three 1.2 mm fins on the top step read fine detail
and tip behaviour. The slab is engraved "TEMP ____ C" - write the
profile's temperature on it with a marker as soon as the print comes
off the plate, or the set is useless.

**How to judge:** print all five (or start with 200 / 210 / 220),
label each, then compare feature by feature across the set: window
roofs (sag = too hot or too cold for bridging), notch undersides
(droop/curl), surface gloss (matte PLA goes shinier as temperature
climbs), stringing between the fins, and layer adhesion (snap a fin -
clean break along a layer line at low temperatures).
