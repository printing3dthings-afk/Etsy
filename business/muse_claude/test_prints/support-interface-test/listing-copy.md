# TEST — Support Interface Test

Title: TEST — Support Interface Test

## Description

Supports are easy to add and miserable to remove — and the surface they
touched usually shows it. This coupon isolates the one setting group that
decides that surface: the support interface.

The part is two legs holding up a flat roof (64 x 30 mm overall). The
roof's underside — flat, 14 mm above the plate, spanning 36 mm — cannot
print without support. Print it twice, once with each profile, remove the
supports, and compare the same underside both ways:

- Stock: supports exactly as the printer ships — tree supports, automatic
  interface, 0.5 mm interface spacing.
- Tuned interface: normal supports with a dense rectilinear interface —
  0.2 mm interface spacing, 0.2 mm top Z distance, 3 interface layers.

Everything else is identical: matte white PLA, 0.20 mm layers, 3 walls.

### How to judge

Remove the supports from both prints the same way, then compare the roof
undersides: flatness, pitting or scarring where the interface touched, and
how hard the supports were to get off. The tuned interface costs a little
more material; the question is whether the surface is worth it.

### Profiles and material

Two profiles of one model — stock vs tuned is the comparison, so there is
no Standard/Optimized pair for this test. Supports are ON in both (the
only test in the set that uses them):

- Stock: verified slice 30 min 32 sec - 14.22 g
- Tuned interface: verified slice 21 min 08 sec - 15.62 g

MakerWorld may display its own re-sliced time and filament estimates.

The gallery images are renders of the plate until the print is photographed.

## Profile copy — Stock

Prints the Support Interface Test (two legs + flat roof, 64 x 30 x 18 mm) with completely stock support settings: tree supports, automatic interface, 0.5 mm interface spacing, 0.2 mm top Z distance. Matte white PLA, 0.20 mm Standard, 3 walls, 15% infill. Verified slice: 30 min 32 sec - 14.22 g. Judge the roof underside after support removal.

## Profile copy — Tuned interface

Prints the Support Interface Test (two legs + flat roof, 64 x 30 x 18 mm) with a tuned support interface: normal supports, rectilinear interface pattern, 0.2 mm interface spacing, 0.2 mm top Z distance, 3 interface top layers. Matte white PLA, 0.20 mm Standard, 3 walls, 15% infill. Verified slice: 21 min 08 sec - 15.62 g. Judge the roof underside after support removal.
