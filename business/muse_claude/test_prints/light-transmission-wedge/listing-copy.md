# TEST — Light Transmission Wedge

Title: TEST — Light Transmission Wedge

## Description

How thick can a printed wall be before the light stops getting through? This
stepped wedge answers it for your filament — the numbers behind lampshades,
lithophanes, tea-light diffusers and glow-through panels.

Six steps on one strip (132 x 44 mm), each 22 mm wide and engraved with its
thickness: 0.8, 1.2, 1.6, 2.0, 2.4 and 3.0 mm.

### How to judge

Print it in the filament you want to characterise. In a dark room, put a phone
flashlight or an LED tea light under the strip and slide it across so each step
sits over the light in turn. Note the brightest step that still looks even (no
visible infill pattern shining through) and the step where the light all but
disappears. A phone light-meter app held at a fixed distance above each step
turns it into numbers.

| Step (mm) | Brightness (1-5) | Even, or pattern showing? | Notes |
|---|---|---|---|
| 0.8 |  |  |  |
| 1.2 |  |  |  |
| 1.6 |  |  |  |
| 2.0 |  |  |  |
| 2.4 |  |  |  |
| 3.0 |  |  |  |

At these thicknesses the steps print mostly as solid shell, so your results
carry over to real walls and diffuser sleeves of the same thickness.

### Profiles and material

Both profiles are matte white PLA, 3 walls, supports off, and deliberately no
ironing — ironing densifies the top skin and would change the transmission
being measured:

- Standard: 0.20 mm Standard - verified slice 17 min 55 sec - 11.99 g
- Optimized: 0.16 mm Optimal - verified slice 20 min 31 sec - 12.87 g

MakerWorld may display its own re-sliced time and filament estimates.

The gallery images are renders of the wedge until the print is photographed.

## Profile copy — Optimized

Prints the Light Transmission Wedge: a 132 x 44 mm strip of six steps at 0.8, 1.2, 1.6, 2.0, 2.4 and 3.0 mm thickness, each engraved with its thickness, for comparing backlight brightness per wall thickness. Matte white PLA, 0.16 mm Optimal, 3 walls, 12% gyroid infill, supports off, no ironing. Verified slice: 20 min 31 sec - 12.87 g. Finer layers keep the thin steps closer to their designed thickness.
