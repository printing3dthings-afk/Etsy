# TEST — Layer Height Comparison Set

Title: TEST — Layer Height Comparison Set

## Description

Everyone knows thinner layers look better and take longer. How much
better, and how much longer, on the surfaces that actually matter? This
set prints one token five times — the same file, the same settings, only
the layer height changes: 0.08, 0.12, 0.16, 0.20 and 0.28 mm.

The token (64 mm across, 24.7 mm tall) is built to show the trade on every
kind of surface: a curved dome where stepping shows first, a sloped side
where it shows worst, flat tops, and fine engraved text ("FINE 123") that
either survives or fills in. All five profiles are matte white PLA,
3 walls, 15% infill, first layer 0.20 mm, no ironing — nothing is allowed
to hide the difference.

### How to judge

Print at least the 0.12, 0.20 and 0.28 profiles (all five if you have
time) and line the tokens up. Read the dome from the side against a light,
run a nail down the slope, and check whether the engraved text is still
crisp. Note the height where YOU stop seeing a difference — that is your
default for decorative parts, and anything finer is for hero surfaces only.

### Profiles and material

Five profiles of one model — the profiles ARE the comparison, so there is
no Standard/Optimized pair for this test:

- 0.08 mm - verified slice 38 min 14 sec - 13.38 g
- 0.12 mm - verified slice 27 min 22 sec - 13.52 g
- 0.16 mm - verified slice 22 min 13 sec - 13.79 g
- 0.20 mm - verified slice 18 min 38 sec - 13.39 g
- 0.28 mm - verified slice 16 min 49 sec - 14.86 g

MakerWorld may display its own re-sliced time and filament estimates.
