# TEST — Thread & Nut-Trap Plate

Title: TEST — Thread & Nut-Trap Plate

## Description

Two fit questions every designer hits: how much clearance does a printed
thread need, and how big do you cut a hex trap so a real nut seats? This
set answers both on one plate.

Threads: two bolt-and-nut pairs, both M16 x 2.0 with true helical ISO
threads (not stacked rings). The bolts are identical; the nuts differ —
one cut with 0.3 mm radial clearance per side, one with 0.4 mm. Screw
each bolt into both nuts and feel the difference: which runs smooth,
which is tight, which is sloppy. (Clearance tiles sit in front of each
pair.)

Nut traps: a plate with hex pockets for M3, M4 and M5 nuts. Each row is
cut at the nut's across-flats + 0.2, + 0.4 and + 0.6 mm (M3: 5.7 / 5.9 /
6.1; M4: 7.2 / 7.4 / 7.6; M5: 8.2 / 8.4 / 8.6), depth = nut height + 0.2
mm. Rows and columns are engraved on the plate. Real nuts are not
included — you supply your own.

### How to test

Threads: run each bolt through both nuts several times (printed threads
bed in). Note smoothness, tightness and wobble for each clearance.
Traps: press a nut of each size into its three pockets. The right trap
seats with firm thumb pressure and the nut doesn't spin when you drive a
bolt into it from the other side.

### Profiles and material

All parts print together as separate pieces on one plate. Both profiles
are matte white PLA, 3 walls, supports off, no ironing (the trap mouths
are fit surfaces — no ironing lip on them). Thread clearances and trap
sizes are identical in both profiles; only the layer height differs, and
threads are exactly where finer layers change the feel:

- Standard: 0.20 mm Standard - verified slice 1 hr 13 min - 43.61 g
- Optimized: 0.16 mm Optimal - verified slice 1 hr 41 min - 45.72 g
