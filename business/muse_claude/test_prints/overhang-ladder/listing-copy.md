# TEST — Overhang Ladder

Title: TEST — Overhang Ladder

## Description

Every printer has an overhang limit — the steepest downward face it can print
with no supports before the surface sags, curls or turns rough. This ladder
finds yours in one print.

Six fin blocks stand on a base plate (170 x 46 mm, 52 mm tall overall). Each
fin has a triangular notch cut from its front-bottom corner, and the notch's
sloped underside is the test face: 30, 40, 50, 60, 70 and 80 degrees from
vertical, with the angle engraved on top of each fin. (80 degrees from vertical
is a nearly flat ceiling — the hardest test; 30 is the gentlest.)

### How to judge

Print it in your usual settings, let it cool, and inspect each underside under
a bright light. Grade each face: clean / slight roughness / sagging strands /
failed. The last clean angle is your working overhang limit for that filament
and fan setup — design and orient parts to stay inside it, or reach for
supports past it.

| Angle from vertical | Clean? | Sagging / curling? | Notes |
|---|---|---|---|
| 30 |  |  |  |
| 40 |  |  |  |
| 50 |  |  |  |
| 60 |  |  |  |
| 70 |  |  |  |
| 80 |  |  |  |

This is a solid, one-time calibration print (about 87 g) — print it once per
filament family or cooling change, not per spool.

### Profiles and material

Both profiles are matte white PLA, 3 walls, supports off (supports would
defeat the test):

- Standard: 0.20 mm Standard - verified slice 1 hr 53 min - 86.69 g
- Optimized: 0.16 mm Optimal - verified slice 3 hr 02 min - 89.17 g

Printing both doubles as an A/B test: thinner layers genuinely print cleaner
overhangs, so compare the same angle across the two prints.

MakerWorld may display its own re-sliced time and filament estimates.

The gallery images are renders of the ladder until the print is photographed.

## Profile copy — Standard

Prints the Overhang Ladder: six fin blocks on a 170 x 46 mm base, each with a notched underside test face at 30, 40, 50, 60, 70 or 80 degrees from vertical, angle engraved on each fin. Matte white PLA, 0.20 mm Standard, 3 walls, 15% infill, supports off. Verified slice: 1 hr 53 min - 86.69 g.

## Profile copy — Optimized

Prints the Overhang Ladder: six fin blocks on a 170 x 46 mm base, each with a notched underside test face at 30, 40, 50, 60, 70 or 80 degrees from vertical, angle engraved on each fin. Matte white PLA, 0.16 mm Optimal, 3 walls, 12% gyroid infill, supports off. Verified slice: 3 hr 02 min - 89.17 g. The finer layers print visibly cleaner overhang faces than the Standard profile — compare the same angle on both prints.
