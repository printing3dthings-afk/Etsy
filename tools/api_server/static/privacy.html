Last updated: May 9, 2026

Overview

OnBrandCraftz Hub is a private, personal shop-management tool used solely by the owner of the OnBrandCraftz Etsy shop. It is not a public application and is not available to third parties.

Data We Access

This application connects to Pinterest and Etsy APIs exclusively on behalf of the shop owner. The following data may be accessed:

  • Pinterest boards and pins belonging to the authenticated account
  • Pinterest account profile information
  • Etsy shop listings, orders, and messages belonging to the shop owner

How Data Is Used

All accessed data is used solely to manage and operate the OnBrandCraftz Etsy shop. Specifically:

  • To create and schedule Pinterest pins promoting shop products
  • To read shop orders, listings, and customer messages
  • No data is sold, shared, or transmitted to any third party
  • No data is stored beyond what is needed for immediate shop operations

Data Storage

API access tokens are stored locally on the shop owner's private device and server. No personal data belonging to customers or third parties is collected or retained.

Third-Party Services

This application uses the following third-party APIs under their respective terms of service:

  • Pinterest API — pinterest.com
  • Etsy Open API — etsy.com
  • Anthropic Claude API — anthropic.com
